# Abayomi David Adesida — Portfolio

Static HTML/CSS/JavaScript portfolio designed for GitHub Pages.

## Files

- `index.html` — portfolio page
- `assets/style.css` — responsive styling
- `assets/script.js` — mobile navigation + footer year
- `assets/Abayomi_David_Adesida_Resume.pdf` — downloadable resume
- `assets/profile-photo.jpg` — profile photo



## Run locally

From this folder:

```bash
python -m http.server 8000
```

Open:

`http://localhost:8000`

## Publish on GitHub Pages

```bash
git init
git add .
git commit -m "Create portfolio website"
git branch -M main
git remote add origin https://github.com/Yormee9054/portfolio.git
git push -u origin main
```

Then on GitHub:

Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
